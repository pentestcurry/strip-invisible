All notable changes to this project are documented here.

## 0.1.0

- Initial release.
- `scan()`, `clean()`, and `summarize()` library API.
- CLI flags: `--write`, `--check`, `--typographic`, `--json`, `--quiet`.
- Detects invisible/zero-width characters, bidi controls, unusual spaces, variation selectors, possible confusables, smart quotes, dashes, ellipsis, and full-width punctuation.
- Reads from files or stdin.
